AccountBank Minimal — тестовая Release-сборка для Apple Silicon и macOS 27.

Запуск: дважды нажмите «Запустить AccountBank.command».
Лаунчер проверяет архив и подпись, затем использует одну временную копию
приложения для этой версии. Профиль хранится в едином каноническом месте:
~/Library/Application Support/AccountBank — он же используется при прямом
запуске AccountBank.app, поэтому сессии не теряются между версиями и
сборками. Если ключ профиля не найден, запуск остановится без создания
нового пустого профиля.
Данные официального Telegram не затрагиваются.
Не запускайте старые комплекты (v11–v13) одновременно с новым: их
архивные копии папок данных содержат копию того же профиля. Запускайте
приложение только через этот лаунчер, а не напрямую из архива или
временной папки.

Проверено автоматически: Release-сборка, arm64, целостность ZIP,
подпись распакованного приложения и путь запуска. Графическое окно,
вход, чаты и одновременная работа 20–30 аккаунтов требуют проверки
в обычном сеансе macOS. Это локальная тестовая сборка без нотариализации.

Ваши Telegram API-данные встроены в приложение. Не публикуйте комплект.
