# AccountBank v43: игнорирование и архив

## Изменения

- Игнорируемые авторы скрываются в истории без пустого пузыря, в новых результатах поиска, превью чатов, цитатах и новых уведомлениях. Список в настройках показывает имя и ID пользователя, позволяет убрать его из списка.
- Локальный архив в «Я - рядом!» открывается одной кнопкой. Внутри — четыре понятных раздела. При ошибке чтения есть повторная попытка; архив не очищается.
- Новые форум-группы облачного архива получают объяснимые название и описание. Код копии сохраняется для восстановления связи после сбоя создания. Старые группы автоматически не переименовываются.
- Для облачного зеркала оставлена одна закрытая форум-группа на аккаунт, а темы разделяются по диалогам. Отдельные группы по типу события умножили бы число чатов на число аккаунтов и разнесли бы изменения и удаления одного диалога по разным местам.
- Строка `id` в профиле — экспериментальное отображение числового Telegram ID, а не описание группы. Подпись теперь указывает тип ID.
- Ошибки чтения архива записываются в журнал без текста сообщений, ключей и путей.

## Границы проверки

- Счётчики непрочитанных, дата последнего сообщения и данные Telegram не переписываются из-за игнорирования. Уже открытый чат нужно открыть заново после изменения списка в настройках; уже открытый поиск — запустить снова.
- Ошибка чтения локального архива на пользовательском профиле не диагностирована: профиль и его ключи не открывались. Новый журнал различает отказ инициализации, записи, SQLite-чтения и проверки записи. Если ошибка повторится, нужна только соответствующая строка `Archive: recent read ...` из журнала без содержимого архива.
- Реальную работу интерфейса и 20–30 аккаунтов должен проверить пользователь в приложении. Успешная сборка подтверждает только компиляцию и упаковку.
