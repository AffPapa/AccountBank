# AccountBank v53: тестовая сборка архива

Пакет: `/Users/dumay/Desktop/PaSEO/Builds.nosync/AccountBank-Minimal-Release-v53-macOS-arm64-Test`.
Запускать через `Запустить AccountBank.command`, не одновременно со старой
версией. Лаунчер сверяет SHA-256 ZIP и подписывает распакованную тестовую копию
в своём временном кэше. Файл профиля остаётся прежним.

## Изменено

- Новые исходные снимки и события удаления по умолчанию сохраняются только из
  личных диалогов с людьми. Остальные чаты можно включить в разделе архива
  настроек; переключение применяется сразу. Старые записи не удаляются.
- Архив получил HMAC-индекс вида события и диалога. При первом открытии
  старые записи индексируются в фоне порциями по 256 с сохраняемым курсором.
  До завершения миграции просмотр пользуется прежним полным поиском.
  Названия чатов и виды событий в новых индексах не хранятся открытым текстом.
- Событие правки с уже загруженным сообщением сохраняет исходный снимок и
  правку одной транзакцией вместо двух.
- В локальном архиве видны состояния пересылки вложения: ожидает отправки,
  сохранено в архивном чате, ошибка, только ссылка/метаданные или неизвестный
  результат старой отправки. У длинной подписи остаётся видимым блок «Стало».

## Автоматическая проверка

- Release-сборка для arm64 успешно скомпилирована.
- `git diff --check` без ошибок.
- ZIP прошёл SHA-256 и `unzip -tq`; скрипт запуска прошёл `zsh -n`.
- На синтетической базе 100 000 строк `EXPLAIN QUERY PLAN` показывает поиск
  по индексам `recent_kind_ts` и `recent_kind_peer_ts` без временной
  сортировки. Синтетическая старая схема сохранила `NULL` для неизвестного
  результата прежней отправки и корректно приняла поле статуса.
- Синтетический SQLite-замер 20 000 строк пакетами по 100: без индекса
  p50/p95/p99 транзакции составили 0,23/0,34/3,29 мс, с индексом —
  0,85/4,51/5,25 мс. Индекс ускоряет поиск ценой дополнительных операций
  записи и места; этот замер не включает шифрование или работу Telegram UI.

Подпись приложения после распаковки в `/private/tmp` автоматически проверит
лаунчер при первом запуске. Эту проверку агент не выполнял: правила проекта
ограничивают его действия папкой PaSEO, а macOS File Provider не позволяет
подписать bundle непосредственно внутри неё.

## Проверка в приложении

1. Запустить v53, переключить компактный список, открыть боковое меню и
   проверить создание чата/канала и вход в архив.
2. Удалить обычное сообщение в личном чате, затем в группе. При выключенном
   новом переключателе в архиве должно появиться только событие из лички.
   Включить переключатель и повторить в группе.
3. Открыть архив правок/удалений дважды. Если старый архив большой, первый
   просмотр может быть медленным из-за фоновой миграции; затем поиск должен
   работать по индексу.
4. Отправить и удалить фото, видео, GIF, голосовое и файл. Проверить наличие
   вложения в топике, статус в локальном архиве, перезапуск и отсутствие
   дубликатов. Отдельно проверить длинную подпись правки.
5. Проверить 1/5/10/20/30 активных тестовых аккаунтов, запуск, память и
   уведомления. Эти измерения не подменяются синтетической базой.

## Остаётся

Ссылки Telegram не заменяют локальные байты фото/видео; надёжный ограниченный
медиакэш и повторная загрузка из него пока не реализованы. Транзакции записи
архива всё ещё могут выполняться в потоке интерфейса; в v53 убрана только
одна лишняя транзакция при обычной правке. Перенос всего журнала на отдельную
последовательную очередь требует отдельной проверки порядка событий и сбоя БД.
