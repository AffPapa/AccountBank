# AccountBank: аудит интерфейса и кода после v40

## Исправлено в этой волне

- В «Я - рядом!» локальные записи отделены от облака и экспорта, архивные кнопки получили разные значки, а поиск по настройкам — русские синонимы.
- Подсказки о перезапуске уточнены, реклама помещена к настройкам сообщений, повторное планирование сохранения параметров удалено.
- Появился список игнорируемых пользователей с удалением из списка. Уже открытый чат следует открыть заново, чтобы обновить его вид.
- Перед чтением архива сохраняется накопленный буфер, поэтому свежие события видны сразу или показана ошибка сохранения.
- Экспорт получает дату и время в имени файла и при обычном повторном экспорте выбирает отдельное имя.

## Проверено по исходникам

- Боковое меню содержит профиль, «Избранное», настройки и штатный переключатель ночной темы. Функции AccountBank находятся в разделе «Я - рядом!» внутри настроек.
- Раздел использует прежние ключи параметров. Переключатели общие для всех аккаунтов; просмотр, экспорт и облачный форум архива работают с активным аккаунтом.
- Пустой regex-фильтр больше не затемняет все сообщения.
- Содержимое архивных записей шифруется AES-GCM. Время записи и состояние очереди облачного зеркала остаются открытыми полями SQLite; называть зашифрованной всю базу нельзя.

## Что нельзя гарантировать

- Если сообщение удалено до получения его текста клиентом, обновление Telegram содержит только ID. Прежний текст восстановить невозможно.
- При ошибке локальной записи удалённое сообщение может быть видно до перезапуска, но не попасть в архив. Для архива нужен отдельный видимый статус ошибки и проверка отказа записи на синтетическом профиле.
- Реальная работа с 20–30 аккаунтами и внешний вид окон не подтверждены. По правилам рабочей папки автоматическое управление рабочим столом запрещено.

## Подтверждённые задачи на следующую волну

1. Вынести синхронные транзакции архива из потока интерфейса, сохранив порядок событий. Нужен замер задержек на синтетическом архиве и отдельная проверка сбоя БД.
2. Ускорить просмотр редкой категории архива: сейчас для 50 совпадений возможно расшифровать до 2 млн записей. Нужен индекс по HMAC типа и диалога с совместимой миграцией.
   Синтетический `EXPLAIN QUERY PLAN` для очереди облачного зеркала также показал `SCAN cloud_mirror` и временную сортировку; индекс следует выбирать по замеру реальной формы очереди, без чтения пользовательского архива.
3. Измерить память и запуск на 1/5/10/20/30 аккаунтах. При каждом старте всё ещё читаются наборы стикеров и GIF; удалять ключи хранилища нельзя.
4. Проверить миграцию старых снимков личных сообщений в архиве на синтетических данных: новый индекс не покрывает все старые записи.
5. Проверить вручную настройки, поиск, узкое окно, смену аккаунта, архив и ночную тему на v41.

Эти задачи не следует отмечать выполненными по одному лишь успешному компилятору или тестовому ZIP.
