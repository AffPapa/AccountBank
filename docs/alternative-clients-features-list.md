# Полный список нестандартных функций альтернативных Telegram-клиентов

Исследование: AyuGram Desktop/Android, 64Gram, Materialgram, Forkgram, Kotatogram,
freshGram, tele, FAgram, TG_custom_desktop, NovaGram, Nagram/NekoX, Nekogram,
exteraGram, Cherrygram, Plus Messenger, Graph Messenger, Nicegram, Swiftgram,
Telegram X, Nullgram, OwlGram, OctoGram, iMe, Telegram-FOSS.
Собрано для передачи реализующему ИИ (клиент: форк Telegram Desktop, macOS, arm64).
В скобках — клиенты-референсы с готовыми реализациями.

## А. Мониторинг и неизменяемость данных

1. ANTI-RECALL, СОХРАНЕНИЕ УДАЛЁННЫХ СООБЩЕНИЙ — сообщения, удалённые собеседником, остаются в чате с пометкой «deleted» и пишутся в локальную БД; переживают перезапуск и чистку кэша (AyuGram, freshGram, tele, TG_custom_desktop).
2. УДАЛЁННЫЕ С МЕДИА + АВТОБЭКАПЫ БД — в БД хранятся и медиафайлы удалённых, БД бэкапится автоматически, восстанавливается свежий валидный бэкап при повреждении (freshGram).
3. ИСТОРИЯ РЕДАКТИРОВАНИЙ — все предыдущие версии отредактированного сообщения с отдельной страницей просмотра; вариант git-diff: старая версия зачёркнута над новой (AyuGram, tele, TG_custom_desktop).
4. УДАЛЁННЫЕ ЧАТЫ/ТОПИКИ ОСТАЮТСЯ — чаты, из которых кикнули/удалили, и удалённые топики остаются в списке с пометкой и историей (freshGram, AyuGram).
5. ЛОГ ОНЛАЙНОВ КОНТАКТОВ — история «кто когда был онлайн» с таймлайном по выбранным контактам (Graph Contact Tracker).
6. УВЕДОМЛЕНИЯ «КОНТАКТ В СЕТИ/ОФЛАЙН» — пуш в реальном времени по выбранным людям (Graph Special Contact; плавающие тосты у Plus).
7. ЛОГ ИЗМЕНЕНИЙ ПРОФИЛЯ КОНТАКТА — таймлайн изменений имени, юзернейма, телефона, аватара (Graph Contact Changes).
8. ЛОГ «КТО ПРОЧИТАЛ МОЁ» — сохранение read-реквизитов исходящих навсегда, с временем (tele).
9. ПОЛНАЯ ЛОКАЛЬНАЯ ИСТОРИЯ ВСЕЙ ПЕРЕПИСКИ — вся переписка в локальной БД, не зависит от сервера и кэша (AyuGram Messages History).
10. СИНХРОНИЗАЦИЯ АРХИВА МЕЖДУ УСТРОЙСТВАМИ — self-host бэкенд, синк истории и состояний прочтения (AyuSync/AyuSyncBackend).
11. MESSAGE DETAILS — время первой отправки, DC отправителя, GPS данных фото, платформа, владелец стикерпака, ID кастомных эмодзи (exteraGram, OwlGram, OctoGram).
12. ДАТА РЕГИСТРАЦИИ АККАУНТА — приблизительная, в профиле (Nicegram RegDate, Materialgram, exteraGram, FAgram).
13. ДАТА ВСТУПЛЕНИЯ УЧАСТНИКА В ГРУППУ (OwlGram).
14. ЭКСПОРТ/ИМПОРТ БД АРХИВА — deep link или меню, перенос архива между машинами (AyuGram tg://ayu/db_export).

## Б. Приватность и скрытность

15. GHOST MODE — не отправлять «прочитано», «онлайн», «печатает», «выбирает стикер» (AyuGram, tele, TG_custom_desktop).
16. ОТПРАВКА БЕЗ ВЫХОДА В ОНЛАЙН — трюк отложенными сообщениями (секунды для текста, формула по размеру для медиа) (AyuGram, tele).
17. READ ON INTERACT — помечать прочитанным только при ответе/действии (AyuGram, FAgram).
18. СТЕЛС ДЛЯ СТОРИС — смотреть сторис не попадая в список зрителей + алерт перед live-сторис (AyuGram, tele).
19. ИНКОГНИТО VIEW-ONCE — просмотр одноразовых медиа без сжигания, ручной «mark as viewed» (tele).
20. СКРИНШОТЫ В СЕКРЕТНЫХ ЧАТАХ — без уведомления собеседника (AyuGram).
21. STREAMER MODE — окна скрыты от захвата экрана (записи, OBS, трансляции) (AyuGram, tele, 64Gram, NovaGram).
22. DURESS PIN — второй пин-код: мгновенный логаут всех аккаунтов + удаление локальных данных + «режим заглушки» (NovaGram).
23. ПРИВЯЗКА К ДАННЫХ К УСТРОЙСТВУ — украденная папка профиля не открывается на другом ПК (NovaGram, DPAPI).
24. СКРЫТЫЕ АККАУНТЫ «ВТОРОЕ ДНО» — аккаунты исчезают из интерфейса, доступ секретным методом (Graph Hidden Accounts, Nicegram Double Bottom).
25. БЛОКИРОВКА ОТДЕЛЬНОГО ЧАТА ПАРОЛЕМ/ПАТТЕРНОМ + мгновенный автолок (Graph Advanced Lock).
26. ПАССКОД НА КАЖДЫЙ АККАУНТ ОТДЕЛЬНО (Nekogram, OwlGram).
27. ОЧИСТКА EXIF/XMP У ОТПРАВЛЯЕМЫХ ФОТО + обезличенные имена сохраняемых файлов (NovaGram).
28. ЧИСТКА ТРЕКИНГ-ПАРАМЕТРОВ ССЫЛОК — utm, fbclid, si и т.д. (tele).
29. ФИЛЬТР СООБЩЕНИЙ ПО СЛОВАМ/REGEX — глобально и по чатам, скрытие без непрочитанных (tele).
30. IGNORE USERS — сообщения выбранных юзеров фейдятся/исчезают (tele).
31. ПЕРСОНАЛЬНЫЕ НАСТРОЙКИ ПРИВАТНОСТИ PER-USER (OctoGram).
32. PEEK LAST SEEN — подглядеть точный «был в сети» скрытый статус (freshGram, tele).
33. СКРЫТИЕ СООБЩЕНИЙ ОТ ЗАБЛОКИРОВАННЫХ (AyuGram, 64Gram, FAgram).
34. ЧЕРНОВИКИ ТОЛЬКО ЛОКАЛЬНО — никогда в облако (tele).
35. DNS ТОЛЬКО ИЗ СВОЕГО СПИСКА через DoH, вырезанная телеметрия (NovaGram).

## В. Обходы ограничений

36. LOCAL TELEGRAM PREMIUM — клиентское включение премиум-косметики без подписки (AyuGram, FAgram, freshGram).
37. ОБХОД NOFORWARDS/PROTECTED CONTENT — копирование, сохранение, выделение, скриншоты в чатах с запретом (AyuGram, TG_custom_desktop, Nagram Forced Copy).
38. ФОРВАРД КОПИЯМИ ИЗ ЗАЩИЩЁННЫХ ЧАТОВ — re-upload медиа при пересылке (tele, AyuForward).
39. СКРЫТИЕ СПОНСОРСКИХ СООБЩЕНИЙ/РЕКЛАМЫ (AyuGram, tele, FAgram).
40. ЛИМИТ АККАУНТОВ ПОВЫШЕН — 10 (64Gram, Kotatogram), 20 (Materialgram), 999 (FAgram), 1536 (tele), безлимит (NekoX, Swiftgram, Nicegram).
41. ЛОКАЛЬНЫЕ ПАПКИ/ПИНЫ/ЗАКРЕПЫ СВЕРХ СЕРВЕРНОГО ЛИМИТА (Kotatogram, FAgram, tele).
42. ТРАНСКРИПЦИЯ ВОЙСОВ БЕСПЛАТНО — без Premium, свои провайдеры (Swiftgram, Nekogram Cloudflare Workers AI, OctoGram, iMe).
43. ПЕРЕВОД ЦЕЛЫХ ЧАТОВ БЕЗ PREMIUM — мультипровайдерный (Google/Yandex/DeepL), автоперевод, перевод ввода, InstantView, био (OwlGram, NekoX, Swiftgram, Nekogram, OctoGram, Graph, iMe).
44. ПОКУПКА STARS БЕЗ KYC — мультичейн-оплата криптой (Cherrygram).
45. ПОКУПКА СКРЫТЫХ ПОДАРКОВ из профиля (Cherrygram).
46. ЭКСПОРТ ЧАТА 10 000 СООБЩЕНИЙ В ОДИН HTML — ускоренное скачивание файлов при экспорте (Materialgram).
47. GIF-МЕДИА-КОНТРОЛЫ, отправка GIF как видео и наоборот, mkv как видео (tele, exteraGram).

## Г. Сортировка и организация чатов

48. ПАПКА/ВКЛАДКА «ГДЕ Я АДМИН / ВЛАДЕЛЕЦ» — отдельный таб чатов по вашим правам (Plus Messenger: вкладки users/groups/channels/bots/unread/admin/creator; Kotatogram: звёздочка у групп, где вы админ).
49. АЛЬТЕРНАТИВНЫЕ СОРТИРОВКИ ЧАТОВ — непрочитанные сверху, свои методы (Plus, NekoX/Nagram).
50. КАТЕГОРИИ ЧАТОВ — локальные группы поверх серверных папок, с сохранением и восстановлением наборов (Plus).
51. ЛЕНТА ВСЕХ КАНАЛОВ — единый таймлайн постов всех ваших каналов (Graph Timeline, exteraGram Channel Feed).
52. HASHTAGS+ — создание/подписка на хэштеги, мгновенная фильтрация по темам (Graph).
53. ПАПКА ПО КЛЮЧЕВЫМ СЛОВАМ — чаты собираются в папку по словам из сообщений (Nicegram).
54. СКРЫТЬ «ВСЕ ЧАТЫ», ПАПКИ ВНИЗ, ЗАПОМНИТЬ ПОСЛЕДНЮЮ ПАПКУ (Nekogram, Swiftgram, 64Gram, OwlGram).
55. ЗАКРЕПЛЁННЫЕ ЧАТЫ СВЕРХ ЛИМИТА — до 100 вместо 5/10 (Plus).
56. МУЛЬТИСЕЛЕКТ ЧАТОВ — выделение нескольких чатов (Alt+клик) и массовые действия: прочитать, mute, архив, папка, удалить/выйти (tele, Plus).
57. ПРЕВЬЮ ЧАТА ТОЛЬКО-ДЛЯ-ЧТЕНИЯ — Alt+клик без входа и прочтений (tele).
58. FAVORITES — избранное чатов, сообщений, эмодзи, стикеров с реордерингом (Graph).
59. RECENT CHATS BAR — переключение последних чатов прямо из открытого чата (Graph).
60. СКРЫТИЕ ПОХОЖИХ КАНАЛОВ, спонсорского MTProxy, превью сообщений в списке (tele, AyuGram).
61. СКРЫТИЕ СТОРИС полностью из списка (64Gram, FAgram, Nekogram, Swiftgram).
62. УЧЁТ ЗАМЬЮЧЕННЫХ В СЧЁТЧИКАХ ПАПОК (Cherrygram).
63. ПАПКА «UNSORTED» — все чаты, не попавшие в папки (tele).
64. БЫСТРОЕ ПЕРЕКЛЮЧЕНИЕ ПАПОК ДОЛГИМ ТАПОМ (Cherrygram).
65. ДОП. ИНФО О ЧАТАХ В ПАПКАХ, тип группы в списке (Kotatogram).

## Д. Сообщения и отправка

66. МУЛЬТИ-ФОРВАРД — пересылка сразу в несколько чатов (64Gram, Kotatogram, Graph, tele).
67. ФОРВАРД БЕЗ ЦИТАТЫ/АВТОРА/ПОДПИСИ, без заголовка «переслано от» (многие: 64Gram, Plus, Forkgram, Kotatogram).
68. SPECIAL FORWARD — редактирование при пересылке: замена ссылок, префиксы/суффиксы, изменение порядка сообщений (Graph).
69. МАРКДАУН-РЕНДЕР ПРИ НАБОРЕ — bold/italic/spoiler/code/цитаты «>» с живым превью (tele).
70. НЕСКОЛЬКО ЧЕРНОВИКОВ НА ЧАТ — с медиа и rich-текстом, восстановление отброшенных (tele).
71. ОТЛОЖЕННАЯ ОТПРАВКА СВОИМ ДВИЖКОМ — клиент сам отправляет scheduled вовремя, пока запущен (tele).
72. ПОДТВЕРЖДЕНИЕ ПЕРЕД ОТПРАВКОЙ — стикеры/GIF/войсы/любые сообщения (tele, OwlGram, FAgram).
73. ТИХАЯ ОТПРАВКА ПО УМОЛЧАНИЮ — везде или по-чатово (tele).
74. HD-ФОТО/ВИДЕО ПО УМОЛЧАНИЮ, JPEG 94–100% (tele, Materialgram, exteraGram).
75. КАЛЬКУЛЯТОР В ПОЛЕ ВВОДА — «= выражение» с инлайн-подсказкой (tele).
76. НЕСКОЛЬКО ЦИТАТ В ОДНОМ ОТВЕТЕ; ответ на удалённое (tele).
77. ЗАКЛАДКИ-ЗАМЕТКИ НА СООБЩЕНИЯ + возврат к месту чтения (tele).
78. ВЫБОР ДО 10 000 СООБЩЕНИЙ вместо 100 (tele).
79. «УДАЛИТЬ ВСЕ МОИ СООБЩЕНИЯ» в чате/группе/топике (tele, NekoX).
80. MESSAGE SHOT — экспорт выбранных сообщений картинкой (1x–4x, выбор темы и содержимого) (AyuGram, tele, FAgram).
81. КОПИРОВАНИЕ КАК MARKDOWN/HTML; копирование текста сервисных сообщений (tele).
82. VIEW AS TL — просмотр любого объекта (сообщение/чат/юзер/стикер) в виде TL-схемы (tele).
83. КОПИРОВАНИЕ CALLBACK-ДАННЫХ инлайн-кнопок ботов (64Gram, Kotatogram, OwlGram, Materialgram, FAgram).
84. SEND WITHOUT «VIA @BOT» — отправка инлайн-результатов без метки бота (Kotatogram, tele).
85. ТЕКСТОВЫЕ АВТОЗАМЕНЫ — свои правила замены при вводе (Kotatogram, Nagram Text Replacer).
86. БЫСТРЫЕ ОТВЕТЫ в группах и каналах — business quick replies без Business-подписки (tele).
87. УПОМИНАНИЕ НЕСКОЛЬКИХ ЮЗЕРОВ подряд из списка @ (tele, Materialgram).
88. ПРАВИЛА ПЕРЕЗАПИСИ ССЫЛОК — x.com→fixupx и свои пресеты (tele).
89. ПРИКРЕПЛЁННЫЕ МЕДИА НАД ПОЛЕМ ВВОДА — свои подписи, drag&drop (tele).
90. ОЧЕРЕДЬ СООБЩЕНИЙ — сообщения ждут за загружаемым медиа, с досрочной отправкой (tele).
91. СТИКЕРЫ С ПОДПИСЯМИ — отправка/редактирование/просмотр (tele).
92. ГРАНИЧНОЕ ПОДТВЕРЖДЕНИЕ ПЕРЕД ПОДАРКАМИ/STARS/ПЛАТНЫМИ ДЕЙСТВИЯМИ — локальный пароль (tele).
