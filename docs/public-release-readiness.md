# Публичный выпуск NeTelegram для Apple Silicon

Состояние на 19 октября 2026: выпуск и кнопка скачивания **не опубликованы**.
Тестовый пакет v53 не подходит для раздачи: он собран с локальной конфигурацией
Telegram API, подписан ad hoc и не прошёл нотариализацию Apple. На сайте нельзя
обещать готовую сборку, пока нет проверенного файла GitHub Release.

## Что должно быть готово

1. Проверить работу на отдельном тестовом профиле: вход, все активные аккаунты,
   сообщения, голосовые/видео, GIF, медиа после удаления, архив и переключатели.
   Синтетические тесты не доказывают работу сервера Telegram.
2. Определить публичное имя: условия Telegram требуют, чтобы в названии со
   словом Telegram перед ним стояло **Unofficial**. В текущем бинарнике
   ещё используется AccountBank; смену имени, bundle ID и путь профиля нужно
   проверить на миграции, прежде чем отдавать приложение пользователям.
3. Использовать одну принадлежащую проекту пару `TDESKTOP_API_ID` и
   `TDESKTOP_API_HASH` для локальных тестов и выпуска. Она хранится только в
   игнорируемом `accountbank-api.local.cmake`, не в исходниках, логах или
   командной строке. Пользователь публичной сборки получает её внутри
   приложения и входит в собственный аккаунт обычным способом. Данные из
   бинарника технически можно извлечь, поэтому конфигурационный файл остаётся
   приватным, но публичную пару нельзя считать секретом после выпуска.
   Опция CMake `ACCOUNTBANK_PUBLIC_RELEASE=ON` требует этот файл и отвергает
   тестовые данные Telegram.
4. Закоммитить только проверенный исходный код, документацию и нужные ссылки
   на подмодули. Рабочие деревья подмодулей сейчас изменены; нельзя включать
   их случайно. `git diff --check`, проверка секретов в новом diff и сборка
   должны пройти на том же SHA, который получит тег.
5. Собрать Apple Silicon приложение в отдельном `out-public`, подписать его
   Developer ID Application с hardened runtime, отправить в Apple Notary
   Service, прикрепить билет и запустить
   `tools/public-release-preflight.command out-public/Release/AccountBank.app`.
   Скрипт требует чистое дерево, локальный API-конфиг, arm64, отсутствие
   данных пользователя, действительную подпись и прикреплённый билет.
6. Упаковать **только** прошедший проверку `.app` в ZIP, проверить список
   файлов архива и SHA-256. Создать GitHub Release из проверенного тега,
   загрузить ZIP и SHA-256. Проверить скачанный asset заново на чистом Mac.
7. После подтверждения URL asset добавить на сайт кнопку «Скачать для Mac»
   со ссылкой на конкретный GitHub Release, версией, требованиями macOS и
   SHA-256. Проверить ссылку на опубликованном сайте и возможность скачать
   файл без авторизации.

## Что уже проверено

- Репозиторий `AffPapa/AccountBank` публичный, ветка по умолчанию `dev`.
- Локальный diff не показал новых находок gitleaks. Пять находок истории
  находятся в начальном upstream-коммите; до тега их нужно классифицировать
  отдельно, без вывода значений в отчёт.
- В исходниках отключены функции, противоречащие обычному поведению Telegram:
  скрытие прочтения/набора, пропуск sponsored messages, удержание удалённых
  сообщений в диалоге, обход запрета копирования и автоматическое сохранение
  исчезающих медиа. Старые локальные архивные записи не удалены.

## Оставшиеся технические риски

- Медиа в архиве сохраняется через Telegram-ссылку и может не дойти до топика
  после удаления оригинала. Локального ограниченного кэша байтов пока нет.
- Часть записи зашифрованного SQLite-архива и облачной очереди выполняется
  в потоке интерфейса; p95/p99 на реальных аккаунтах не измерены.
- До независимой GUI-проверки и настройки Apple Developer ID публичный
  выпуск остаётся закрыт проверкой.

Официальные требования: [Telegram API terms](https://core.telegram.org/api/terms),
[свой API ID](https://core.telegram.org/api/obtaining_api_id),
[Apple Developer ID](https://developer.apple.com/developer-id/),
[notarization](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution),
[GitHub Releases](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases).
