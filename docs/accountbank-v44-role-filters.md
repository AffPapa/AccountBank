# AccountBank v44: папки по роли

## Что изменено

- Старую локальную папку Admin заменяют четыре вкладки: «Админ в чатах», «Админ в каналах», «Владелец чатов», «Владелец каналов».
- «Чаты» здесь означают обычные группы и мегагруппы; «каналы» — вещательные каналы. Владелец не дублируется во вкладке администратора.
- Папки локальные: не отправляются в Telegram API, не расходуют лимит облачных папок и доступны без Premium. Старый ID Admin сохранён за «Админ в чатах».
- Архивированные группы и каналы включаются после загрузки их истории клиентом. Смена роли, участия и типа чата обновляет вкладки.
- Устаревший общий экран «Где я администратор» удалён из «Я - рядом!». Локальные вкладки не предлагаются в редакторе облачных папок.

## Проверка

- Независимый просмотр diff не нашёл P0/P1: проверены фильтры, обновление ролей, лимит Premium, порядок вкладок, горячие клавиши и защита локальных ID от API.
- Release arm64, повторная сборка без изменений и упаковка проверяются отдельно. Компиляция не подтверждает правильный состав папок в живом аккаунте.
- Ручная проверка: аккаунт админ обычной группы, админ канала, владелец группы, владелец канала; смена прав/выход; архивированный чат; бесплатный аккаунт с облачными папками на лимите; переход между вкладками через меню и клавиатуру.
- Память и CPU при 20–30 аккаунтах не измерены. Четыре локальные папки добавляют четыре проверки роли при обновлении истории; кэш без надёжной инвалидации не вводился.
