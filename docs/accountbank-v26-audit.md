## Подтверждено по исходникам

- В v25 есть обработка двух путей серверного удаления. При включённом `keep-deleted` сообщение остаётся в памяти текущего сеанса и получает маркер; после перезапуска оно в чат не восстанавливается.
- Архив записывает текст и метаданные загруженных сообщений, снимки перед редактированием, удаления, изменения online-статуса и границу прочтения исходящих сообщений. Он не содержит полный серверный архив и не определяет, какой именно человек прочитал сообщение.
- Меню экспорта вызывает `MessageArchive::exportTo` для активного аккаунта. Результат — **незашифрованный** JSON в стандартной папке загрузок AccountBank. Другие аккаунты не экспортируются этим действием.
- Предел архива — 2 миллиона строк на аккаунт. Достигнув его, клиент прекращает новые записи и пишет сообщение в локальный лог; UI об этом пока не предупреждает.

## Исправлено после v25

- Из локального чекпойнт-коммита удалены оба случайно добавленных каталога сборки (`out-size-os`, `out-size-oz`) и добавлено правило игнорирования будущих `out-*`. В сгенерированных заголовках, попавших в старый локальный коммит, был API hash. Значение не выводилось и не копировалось. Старые объекты Git могут сохраняться в локальном reflog; публикация старого SHA недопустима.
- Экспорт перед чтением сбрасывает очередь архива, создаёт каталог назначения, пишет JSON атомарно с правами только владельца и возвращает ошибку при повреждённой записи, ошибке SQLite или неполной записи файла. Ошибка записи в SQLite больше не считается успешной.
- Время событий теперь Unix milliseconds; добавлен счётчик для нескольких событий за одну миллисекунду. Проверяется результат генератора nonce и HMAC.
- Маркер удалённого сообщения сохраняет текстовые сущности и форматирование исходного текста.

## Не доказано

- Запуск v26 в пользовательском GUI, экспорт реального архива, вход/перезапуск и 20–30 подключённых аккаунтов. Сборка и проверка пакета не заменяют эти проверки.
- Корректность unread-счётчика после серверного удаления: `markContentsRead(false)` очищает признаки непрочитанного медиа, реакций и упоминаний, но не доказывает пересчёт общего числа непрочитанных сообщений.
- Восстановление удалённых сообщений в самом чате после перезапуска не реализовано. Доступен только архивный JSON.

## Правила проверки на живом профиле

Запускать только одну копию клиента с профилем. Сначала проверить обычное сообщение, правку, удаление, экспорт и перезапуск на одном тестовом аккаунте. После этого отдельно проверить несколько аккаунтов и размер/скорость. Не открывать JSON в общей папке и не передавать его третьим лицам: он содержит открытый текст сообщений.
