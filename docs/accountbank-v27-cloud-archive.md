## Поведение

- На каждом аккаунте при первом разрешённом событии правки или удаления создаётся собственный **приватный канал** `AccountBank Archive`. Его также можно создать и открыть через главное меню → `Open archive chat`.
- Перед применением правки клиент сохраняет прежнюю версию в локальный зашифрованный архив. Текстовая копия со строками «До изменения» или «Перед удалением», ID чата и сообщения и датой отправляется в приватный канал.
- Очередь отправки хранится в локальном архиве и переживает перезапуск. Адрес канала хранится зашифрованно. По одному событию отправляется один пост; постоянный `random_id` уменьшает риск дубля при повторе.
- Сообщения из чатов с запретом сохранения/пересылки, сообщения с таймером и защищённые медиа **не отправляются** в облачный архив.

## Ограничения

- Это копия **локального старого текста**, а не настоящий Telegram forward. К моменту получения события правки сервер уже хранит новую версию. Старая версия медиафайла в канал не копируется; остаются текст и отметка о медиа. Для длинного текста в канал уходит начало до 3500 символов; полная версия остаётся локально.
- Канал — обычное облачное хранилище Telegram, не секретный чат с сквозным шифрованием. Он виден на других устройствах этого же аккаунта.
- Создание и отправка по реальному Telegram API пока не проверены в GUI: проверены только компиляция, пакет и статический путь по коду. Возможны серверные ограничения на создание каналов и отправку.
- Если запрос создания канала завершится ошибкой или ответ потеряется после создания, автоматический повтор в текущем сеансе остановится. Не создавайте вручную много одинаковых каналов: сначала проверьте список чатов аккаунта.
- Из старых записей локального архива, сделанных до v27, облачная очередь не формируется. Новые правки и удаления отправляются после установки v27.

## Проверка

На тестовом аккаунте откройте главное меню → `Open archive chat`; после создания откройте пункт повторно. Из другого аккаунта отправьте обычный текст, затем измените его. В приватном канале должна появиться прежняя версия, а локальный JSON должен содержать снимок правки. Повторите после перезапуска. Отдельно проверьте, что защищённый чат не создаёт облачный пост.
