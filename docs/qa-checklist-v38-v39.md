## Известные ограничения (не баги)

- Автозамены: при срабатывании теряется форматирование сообщения (v1).
- Peek: работает, только если статус скрыт из-за ТВОЕЙ приватности; при плохой сети тост об ошибке.
- Матрица прав — read-only, без прав топиков.
- Владелец стикерпака — только для своих паков (сервер не отдаёт creator id чужих).
- Локальные закрепы: без drag-reorder, без отдельной секции-заголовка.
- Непрочитанные сверху поднимают только НЕзаглушенные чаты (семантика Telegram).
- Regex-фильтр — только визуальное затемнение; уведомления и счётчики не гасятся.
