# AccountBank: объединённый план внедрения нестандартных функций

Синтез трёх исследований (десктоп-форки, Android-форки, спец-категории).
ИИ-функции исключены по требованию владельца. Порядок — от маленьких к большим.

Обозначения: **[C]** — отдать Codex (легально, он не откажется); **[Я]** — делает
владелец/старший агент (Codex назовёт «незаконным»); ✅ — уже реализовано в AccountBank
(не переделывать); (S) пара часов, (M) до дня, (L) несколько дней.

## 0. Правила для Codex

- Репозиторий: `/Users/dumay/Desktop/PaSEO/AccountBank`, ветка `accountbank/bootstrap`.
- Сборка: `cmake --build out-size-oz --config Release --target Telegram -j 8` — зелёная
  после каждого пункта; smoke: запуск бинаря с `-workdir` во временную папку
  (реальный профиль `~/Library/Application Support/AccountBank` не трогать).
- Стиль: `AGENTS.md` + `REVIEW.md` (табы, `u"..."_q`, минимум комментариев).
- Настройки — только через kv-префы (`readPref/writePref`), не через бинарный стрим.
- Каждый этап — отдельный маленький коммит с понятным subject.
- Ничего из помеченного ✅ и из трека [Я] не трогать; список «незаконного» не обсуждать.
- Новые строки локализации — в конец `lang.strings`.

## 1. Уже реализовано ✅ (не переделывать)

30 слотов аккаунтов; единый стабильный профиль; ghost mode (прочитано/онлайн/typing/
сторис); автосейв view-once/TTL фото+видео+войс и всех просмотренных сторис (в `ttl/`
и `stories/`); скрытие спонсорских; anti-recall (удалённые остаются в чате с маркером
+ архив); история правок и лог удалённых в зашифрованном SQLite-архиве (AES-256-GCM,
ключ из локального ключа аккаунта); лог онлайнов и лог «кто прочитал» в архиве;
экспорт архива в JSON из главного меню; last seen в списке диалогов; streamer mode
(анти-захват окон); peer/message ID; `tg://user?id=`; причина ограничения чата.

1. Codex идёт по этапам C1→C6, по 3–7 функций за запуск, сборка зелёная после каждой.
2. Параллельно/после — трек Я по приоритету владельца: сначала Я1 (быстрые
